# Asset sources

## neon-portrait.webp

- **What:** the full-body portrait of the agent Neon from VALORANT.
- **Owner:** Riot Games. This is not open-source artwork.
- **Used under:** Riot Games' fan-content policy ("Legal Jibber Jabber",
  https://www.riotgames.com/en/legal), which allows free, non-commercial fan
  projects that display Riot's disclaimer (in the page footer). The project
  doesn't present itself as official and uses no Riot logos.
- **Retrieved:** 2026-10-05 from the community-run asset mirror at
  https://media.valorant-api.com/agents/bb2a4828-46eb-8cd1-e765-15848195d751/fullportrait.png
  (2048×1860 PNG, 792 KB).
- **Changes:** cropped to the non-transparent area, resized to 640×782, and
  saved as WebP at quality 82 (85 KB). It is bundled with the site instead of
  hotlinked, so visitors' browsers never contact the mirror.
